Tech Netra is an ACCESSIBILITY-FIRST voice/audio code assistant for blind 
and low-vision developers.

Key Features:
  ✅ File Upload        - Load Python, JS, Java, C++ files
  ✅ Voice Code Gen     - Dictate code requirements (with microphone!)
  ✅ Vibe Code Gen      - Generate code with different personalities
  ✅ Editable Editor    - Type to edit with line numbers
  ✅ Voice Navigation   - Jump to functions/classes/loops
  ✅ Full Accessibility - Keyboard + Voice + Screen Reader support

================================================================================
                      HOW TO DEPLOY (10 MINUTES)
================================================================================

STEP 1: Deploy Backend on Render (~5 min)
  1. Go to https://render.com
  2. Click "New" → "Web Service"
  3. Connect GitHub → Select Project-Rajiv
  4. Name: tech-netra-backend
  5. Set environment variables:
     - ANTHROPIC_API_KEY (from your backend/.env)
     - ANTHROPIC_MODEL = claude-haiku-5-5
     - ALLOWED_ORIGINS = https://tech-netra.vercel.app
  6. Click Deploy
  7. Wait for green "Live" status
  8. COPY your backend URL (e.g., https://tech-netra-abc.onrender.com)

STEP 2: Deploy Frontend on Vercel (~3 min)
  1. Go to https://vercel.com
  2. Sign up with GitHub
  3. Click "New Project"
  4. Import Project-Rajiv
  5. Before deploying, set environment variable:
     - NEXT_PUBLIC_API_URL = [paste your Render backend URL]
  6. Click Deploy
  7. Wait 2-3 minutes
  8. Your app is LIVE! 🎉

STEP 3: Test It
  1. Open your Vercel URL
  2. Try Alt+U (file upload)
  3. Try Alt+G (code generator)
  4. Try Alt+B (vibe code)
  5. Try typing in editor

================================================================================
                        KEYBOARD SHORTCUTS
================================================================================

Feature Control:
  Alt+U ........... Open File Upload
  Alt+G ........... Open Code Generator
  Alt+M ........... Use Microphone (in Code Gen)
  Alt+B ........... Open Vibe Code Generator
  Alt+D ........... Open Debugger
  Alt+A ........... Visual Audit

Navigation:
  Alt+F ........... Jump to Next Function
  Alt+C ........... Jump to Next Class
  Alt+L ........... Jump to Next Loop
  Alt+I ........... Jump to Next If
  Shift+Alt+[F/C/L/I] ... Jump Backward

Settings:
  Alt+H ........... Help & Shortcuts
  Alt+V ........... Voice Control
  Alt+± ........... Text Size
  Alt+P ........... Symbol Level
  Escape ......... Close Dialog
  Enter .......... Accept Generated Code
