## 🎯 Next Steps

### To Get Started
```bash
# 1. Set API key
echo "ANTHROPIC_API_KEY=sk-ant-..." > backend/.env

# 2. Start backend
cd backend && py -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 3. Start frontend (new terminal)
cd frontend && npm run dev

# 4. Open browser
http://localhost:3000
```
